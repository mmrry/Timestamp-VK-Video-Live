# VK Video Live — точное время VOD и Моментов

Userscript для [live.vkvideo.ru](https://live.vkvideo.ru), который заменяет относительные даты («вчера», «7 ч. назад») на точные дату и время в формате `ДД.ММ.ГГГГ ЧЧ:ММ:СС`.

## Что делает

- **Записи (VOD)** показывают время фактического начала стрима (`startTime`).
- **Моменты (клипы)** показывают время создания (`createdAt`).
- Время ставится на карточках в списках записей и моментов и на странице самой записи или момента.
- Кнопки, вкладки и левая панель («История просмотра», каналы, рекомендации) не затрагиваются.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Firefox, Edge).
2. Откройте `vkvideo-vod-exact-time.user.js` и подтвердите установку, либо создайте новый скрипт в Tampermonkey и вставьте код.
3. Обновите страницу live.vkvideo.ru.

## Настройки

В начале скрипта:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `TIME_FIELD` | `'startTime'` | Время начала стрима (`startTime`) или время создания записи (`createdAt`) |
| `REPLACE_RELATIVE_DATE` | `true` | `true` заменяет относительную дату на странице записи, `false` добавляет отдельную строку под заголовком |

## Как работает

Скрипт перехватывает ответы API (`fetch` и `XMLHttpRequest`) в контексте страницы и собирает из JSON идентификаторы записей и клипов с временными метками. Если данные пришли через SSR и запроса не было, он сам запрашивает `api.live.vkvideo.ru` через `GM_xmlhttpRequest`. Изменения DOM в SPA отслеживаются через `MutationObserver` и хуки `history.pushState`/`replaceState`.

Время отображается в часовом поясе браузера.

## Если что-то сломалось

Классы на сайте содержат хэш-суффиксы (`VideoInfo_passed_XXXXX`), которые меняются между сборками, поэтому скрипт матчит их по префиксу. Если после обновления сайта даты пропали или появились не там, пришлите outerHTML проблемного элемента из DevTools.
